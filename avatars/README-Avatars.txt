KF2 bot avatars - how to use

1. Unzip KF2-Avatars.exe anywhere, for example into
   Documents\My Games\KillingFloor2\KFGame
2. In Steam: right-click Killing Floor 2, then Properties, then Launch Options.
   Paste this (use the real path to the exe):
   "C:\full\path\to\KF2-Avatars.exe" %command%
   Then press Play as usual. There is no window; it runs quietly while the game is open.
3. Put your pictures (png, jpg, gif, bmp) in
   Documents\My Games\KillingFloor2\KFGame\BotAvatars
   The folder is created the first time you run it.
4. In game, turn bot avatars on once with the console command:
   mutate SetBotAvatars true
5. If Windows warns about an unknown app, click "More info" and then "Run anyway".
6. No pictures showing? Open KFGame\Logs\KF2-Avatars.log and check it.

You can also just double-click KF2-Avatars.exe: it starts the game through Steam.
